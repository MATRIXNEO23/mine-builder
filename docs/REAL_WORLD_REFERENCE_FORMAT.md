# Real-world measured references

Place a JSON file under the Minecraft config folder: `config/minebuilder/references/<id>.json`.

Example for a hypothetical measured building (NOT a real landmark):

```json
{
  "name": "Sample measured building",
  "width_m": 12,
  "depth_m": 9,
  "height_m": 7,
  "source": "My measured floor plan"
}
```

Type `riferimento <id>` in Banco IA and press `Invia a GPT` to view the recorded dimensions and source. IDs use lowercase letters, digits, underscore and hyphen.

The reference reader works entirely locally, with no extra services. It does not yet parse photographs or floor plans, perform web research, or automatically reconstruct the measured building. Measurements must be supplied and verified by the user; the system must not invent dimensions.

## Research and image analysis (experimental)

In Banco IA, use `cerca edificio San Siro` to search public Wikimedia Commons image references. Results include original Commons page links and previews where available. This is public reference discovery, not a guarantee that every result depicts the requested building.

Place a PNG or JPEG under `config/minebuilder/references/images/` and enter `analizza immagine example.png` (or `.jpg`, `.jpeg`). The file must be at most 4 MiB. The image is transmitted to the already connected ChatGPT model for interpretation. The model must support image input; otherwise the request fails and the user is informed. Do not upload private plans without permission.

These are separate research and analysis capabilities: the tool does not automatically download images from Commons or derive certified metric dimensions from a photo. A full, verified 1:1 building blueprint is not generated by these commands yet.
